# tom_basics bridge

The `tom_basics` bridge exposes the foundation types of `package:tom_basics`
(logging, platform/runtime detection, the base exception) to D4rt scripts.
Bridges are generated by `d4rtgen` into
`lib/src/tom_basics/tom_basics_bridges.b.dart` and registered through
`TomDartscriptBridges.register` (see [`README.md`](../README.md)).

Scripts reach this surface by importing the upstream barrel:

```dart
import 'package:tom_basics/tom_basics.dart';
```

## Bridged classes

| Class | Purpose |
| ----- | ------- |
| `TomBaseException` | Base exception carrying a resource `key`, `defaultUserMessage`, `uuid`/`requestUuid`, `timeStamp`, `parameters`, and `rootException`. |
| `TomLogLevel` | Bitmask log level (see below); supports `+`/`-` composition and `matches`. |
| `TomLogger` | The logger type behind the global `tomLog`. |
| `TomLoggable` | Mixin/interface for objects that log. |
| `TomLogOutput` | Abstract log sink. |
| `TomConsoleLogOutput` | Console implementation of `TomLogOutput`. |
| `TomPlatformUtils` | Platform capability accessor. |
| `TomFallbackPlatformUtils` | Default no-op `TomPlatformUtils`. |
| `TomEnvironment` | Named runtime environment (`env`, `parent`, `isTest`, `isDevelopment`). |
| `TomPlatform` | Named platform value (`name`); knows how to initialize itself. |
| `TomRuntime` | Static registry of platforms and environments. |

## Global variables

| Variable | Type | Notes |
| -------- | ---- | ----- |
| `tomLog` | `TomLogger` | The process-wide logger (`tomLog.info(...)`, `.debug`, `.warn`, …). |
| `platformWeb`, `platformMacos`, `platformWindows`, `platformAndroid`, `platformIos`, `platformLinux`, `platformFuchsia` | `TomPlatform` | The built-in platform constants; their `name` is the lower-case id (e.g. `"macos"`, `"linux"`). |
| `noTomPlatform` | `TomPlatform` | The `"none"` sentinel platform. |
| `defaultTomEnvironment`, `noTomEnvironment` | `TomEnvironment` | The default and sentinel environments. |

## Global functions

| Function | Signature | Behaviour |
| -------- | --------- | --------- |
| `limited` | `String limited(Object? o, dynamic maxLength)` | Stringifies `o` and, if longer than `maxLength`, truncates to `maxLength` characters and appends `...`. |

## Log levels

`TomLogLevel` is a bitmask. The built-in singletons resolve to these patterns:

| Level | `levelPattern` |
| ----- | -------------- |
| `none` | 0 |
| `trace` | 1 |
| `debug` | 2 |
| `traffic` | 4 |
| `info` | 8 |
| `warn` | 16 |
| `status` | 256 |
| `error` | 512 |
| `severe` | 1024 |
| `fatal` | 2048 |
| `all` | 65535 |

Levels compose with `+` (union) and `-` (difference); `matches(messageLevel)`
tests whether a message at `messageLevel` passes a configured level. `byName`
resolves a level from its string name.

```dart
import 'package:tom_basics/tom_basics.dart';

main() {
  // Composition
  var both = TomLogLevel.debug + TomLogLevel.info; // levelPattern == 10

  // Gating
  var passes = TomLogLevel.all.matches(TomLogLevel.info); // true

  // The global logger
  tomLog.info('hello from d4rt');

  // Truncation helper
  return limited('abcdefghij', 4); // 'abcd...'
}
```

## Tests

Bridge coverage lives in
[`test/replay/test_d4rt_tom_basics.d4rt`](../test/replay/test_d4rt_tom_basics.d4rt),
run via the replay harness (`d4rt -run-replay <file> -test`, see
[`doc/testing.md`](testing.md)). The suite exercises `tomLog`, the
`TomLogLevel` constants and composition, the platform constants,
`TomBaseException`, `TomEnvironment`, `TomPlatform`, and `limited`.
