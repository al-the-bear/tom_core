# tom_md2latex bridge

The `tom_md2latex` bridge exposes the Tom Framework Markdown→LaTeX converter
(`package:tom_md2latex`) to D4rt scripts — the static convenience API, the
markdown parser + element model, the LaTeX macro set, and the file/directory
converter. Bridges are generated by `d4rtgen` into
`lib/src/tom_md2latex/tom_md2latex_bridges.b.dart` and registered through
`TomDartscriptBridges.register` (see [`README.md`](../README.md)).

Scripts reach this surface by importing the upstream barrel:

```dart
import 'package:tom_md2latex/tom_md2latex.dart';
```

The bridge covers all 4 source files exported by `tom_md2latex.dart`
(23 classes, no enums, globals, or top-level functions).

## Modules

### Convenience API

| Class | Purpose |
| ----- | ------- |
| `Md2Latex` | Static one-call API: `convertString`, `convertFile`, `convertFileToString(Sync)`, `convertDirectory`, `parse`. |

### Markdown parser & element model

| Class | Purpose |
| ----- | ------- |
| `MarkdownParser` | Parses a markdown string into a `ParsedMarkdown` element tree (`parse()`). |
| `MarkdownParserOptions` | Parser options (`detectAsciiDiagrams` true by default, `asciiDiagramPatterns`). |
| `ParsedMarkdown` | Parsed document (`title`, `author`, `date`, `generateToc`, `tocDepth`, `elements`). |
| `MarkdownElement` | Sealed base of the element types below. |
| `HeadingElement`, `ParagraphElement`, `CodeBlockElement`, `InlineCodeElement` | Heading / paragraph / fenced-code / inline-code elements. |
| `TableElement`, `UnorderedListElement`, `OrderedListElement`, `BlockQuoteElement` | Table / bullet-list / numbered-list / block-quote elements. |
| `HorizontalRuleElement`, `LinkElement`, `ImageElement`, `RawTextElement` | Rule / link / image / raw-text elements. |

### LaTeX macros

| Class | Purpose |
| ----- | ------- |
| `LatexMacros` | The LaTeX macro/preamble set. |

### File & directory converter

| Class | Purpose |
| ----- | ------- |
| `MdLatexConverter` | The conversion engine (`convert`, `convertFile`, `convertAll`). |
| `MdLatexConverterOptions` | Conversion options (`documentClass`, `author`, `generatePreamble`, `generateToc`, `tocDepth`, `excludePatterns`). |
| `MdLatexConverterResult` | Directory-conversion statistics. |
| `ConvertedFile` | A converted file's source + output paths. |
| `ConversionError` | A per-file conversion failure. |

## Example

```dart
import 'package:tom_md2latex/tom_md2latex.dart';

main() {
  // Static, in-memory conversion — no IO.
  var latex = Md2Latex.convertString(
    markdown: '# Hello\n\nWorld',
    generatePreamble: false,
  );

  // Inspect the parsed element tree.
  var parsed = Md2Latex.parse('# Title\n\nbody');

  return [latex.contains('section'), parsed.title, parsed.elements.length];
  // [true, 'Title', 2]
}
```

## Tests

Bridge coverage lives in
[`test/replay/test_d4rt_tom_md2latex.d4rt`](../test/replay/test_d4rt_tom_md2latex.d4rt),
run via the replay harness (`d4rt -run-replay <file> -test`, see
[`doc/testing.md`](testing.md)). The suite exercises the element value carriers
(`HeadingElement`/`ParagraphElement`/`CodeBlockElement`/`ImageElement`/
`LinkElement`/`UnorderedListElement`/`OrderedListElement`/`TableElement`), the
`MarkdownParserOptions` defaults, an end-to-end `MarkdownParser(...).parse()`,
the `Md2Latex.convertString`/`parse` static API, and class-existence for the
converter types.

> distinct source URIs, **distinct classes**. In the **full-binary**

> the resolution is a disambiguation by source URI (not a dedup-by-identity
> collapse); deferred to the analyze/replay gate (items 75-76). `dart analyze
