# tom_process_monitor bridge

The `tom_process_monitor` bridge exposes the Tom Framework process-lifecycle
manager (`package:tom_process_monitor`) to D4rt scripts — the process registry
model, the file-based registry services, the aliveness/startup checks, the
local & remote client APIs, the HTTP daemon, and the re-exported
`tom_basics_network` retry/server-discovery helpers. Bridges are generated by
`d4rtgen` into
`lib/src/tom_process_monitor/tom_process_monitor_bridges.b.dart` and registered
through `TomDartscriptBridges.register` (see [`README.md`](../README.md)).

Scripts reach this surface by importing the upstream barrel:

```dart
import 'package:tom_process_monitor/tom_process_monitor.dart';
```

The bridge covers all 31 source files exported by `tom_process_monitor.dart`
(37 classes, 1 enum, 1 global variable, 1 top-level function), including the
`tom_basics_network` re-exports.

## Modules

### Process model — config & state

| Class / Enum | Purpose |
| ------------ | ------- |
| `ProcessConfig` | Declarative process definition (`id`, `name`, `command`, `args`, `workingDirectory`, `autostart`, …). |
| `ProcessEntry` | A registered process record (`id`, `name`, `command`, `registeredAt`, `state`, `enabled`, `autostart`). |
| `ProcessStatus`, `MonitorStatus` | Live process status + monitor-wide status snapshot. |
| `RestartPolicy` | Restart configuration (`maxAttempts` 5, `backoffIntervalsMs`, `retryIndefinitely` false; `RestartPolicy.defaultPolicy`). |
| `AlivenessCheck` | HTTP aliveness probe (`enabled`, `url`, `intervalMs` 3000, `timeoutMs` 2000, `consecutiveFailuresRequired` 2). |
| `StartupCheck` | Startup-readiness probe (`maxAttempts`, `initialDelayMs`). |
| `RemoteAccessConfig`, `PartnerDiscoveryConfig`, `AlivenessServerConfig` | Remote-access, partner-discovery, and aliveness-server configuration. |
| `WatcherInfo`, `ProcessRegistry` | Watcher-instance record + the parsed file-based registry document. |
| `ProcessState` (enum) | `stopped`, `starting`, `running`, `stopping`, `crashed`, `retrying`, `failed`, `disabled` (8 values; `ProcessStateExtension.toJson`/`fromJson`). |

## Example

```dart
import 'package:tom_process_monitor/tom_process_monitor.dart';

main() {
  // A declarative process definition.
  var cfg = ProcessConfig(
    id: 'p1',
    name: 'svc',
    command: 'dart',
    args: ['run', 'server.dart'],
  );

  // A restart policy + aliveness probe.
  var policy = RestartPolicy(maxAttempts: 10, retryIndefinitely: true);
  var alive = AlivenessCheck(enabled: true, url: 'http://localhost:8080/health');

  // A discovered server (getters derive from the status map).
  var ds = DiscoveredServer(
    serverUrl: 'http://localhost:8080',
    status: {'service': 'pm', 'port': 8080},
  );

  return [cfg.id, cfg.autostart, policy.maxAttempts, alive.intervalMs, ds.port];
  // ['p1', true, 10, 3000, 8080]
}
```

discovery types.
