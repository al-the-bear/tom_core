# tom_dist_ledger bridge

The `tom_dist_ledger` bridge exposes the Tom Framework distributed-ledger API
(`package:tom_dist_ledger`) to D4rt scripts — the ledger API (operations,
calls, callbacks), the local file-backed ledger, the remote ledger client, and
the re-exported `tom_basics_network` retry/server-discovery helpers. Bridges
are generated by `d4rtgen` into
`lib/src/tom_dist_ledger/tom_dist_ledger_bridges.b.dart` and registered through
`TomDartscriptBridges.register` (see [`README.md`](../README.md)).

Scripts reach this surface by importing the upstream barrel:

```dart
import 'package:tom_dist_ledger/tom_dist_ledger.dart';
```

The bridge covers 9 source files (29 classes, 4 enums, 1 global variable, 1
top-level function), including the `tom_basics_network` re-exports.

## Modules

### Ledger API — operations & calls

| Class | Purpose |
| ----- | ------- |
| `Ledger` | The distributed-ledger entry point. |
| `Operation`, `LocalOperation`, `RemoteOperation` | An in-flight operation (local / remote). |
| `Call`, `SpawnedCall`, `CallLifecycle` | A call within an operation + its lifecycle interface. |
| `OperationHelper`, `SyncResult` | Operation helper + sync outcome. |
| `OperationFailedInfo`, `OperationFailedException` | Operation-failure carrier + exception. |

### Callbacks & logging

| Class / Enum | Purpose |
| ------------ | ------- |
| `LedgerCallback`, `OperationCallback`, `CallCallback` | Event-callback structures (backup, log lines, heartbeat errors, crash notification). |
| `CleanupHandler` | Cleanup-handler hook. |
| `DLLogLevel` (enum) | `debug`, `info`, `warning`, `error`. **Note:** an extension overrides `.name` to return the upper-case label (`DLLogLevel.debug.name == 'DEBUG'`). |

### Base & value types

| Class / Enum | Purpose |
| ------------ | ------- |
| `LedgerData`, `CallFrame`, `TempResource` | Ledger document + call-frame + temp-resource records. |
| `HeartbeatResult` | Local heartbeat outcome (`abortFlag`, `ledgerExists`, `heartbeatUpdated`, `callFrameCount`, `tempResourceCount`, `heartbeatAgeMs`). |
| `HeartbeatError` | Heartbeat failure (`type`, `message`, `cause`). |
| `HeartbeatErrorType` (enum) | `ledgerNotFound`, `lockFailed`, `abortFlagSet`, `heartbeatStale`, `ioError`. |
| `FrameState` (enum) | `active`, `crashed`, `cleaningUp`, `cleanedUp`. |
| `OperationState` (enum) | `running`, `cleanup`, `failed`, `completed`. |

### Local ledger

| Class | Purpose |
| ----- | ------- |

### Remote client

| Class | Purpose |
| ----- | ------- |
| `RemoteLedgerClient`, `RemoteLedgerException` | HTTP client for a remote `LedgerServer` + its failure. |

### Networking — retry & discovery (`tom_basics_network`)

| Class | Purpose |
| ----- | ------- |
| `RetryConfig`, `RetryExhaustedException` | Retry configuration (`retryDelaysMs`, `onRetry`) + exhaustion failure. |

| `DiscoveryOptions`, `DiscoveryFailedException` | Discovery options + failure. |

## Global variables

| Variable | Purpose |
| -------- | ------- |
| `kDefaultRetryDelaysMs` | Default retry delays `[2000, 4000, 8000, 16000, 32000]` ms. |

## Global functions

| Function | Purpose |
| -------- | ------- |
| `withRetry(...)` | Executes an async operation with retry logic per a `RetryConfig`. |

## Example

```dart
import 'package:tom_dist_ledger/tom_dist_ledger.dart';

main() {
  // A heartbeat error carrier.
  var err = HeartbeatError(
    type: HeartbeatErrorType.lockFailed,
    message: 'locked',
  );

  // Retry configuration + default delays.
  var rc = RetryConfig();

  // A discovered server (getters derive from the status map).
  var ds = DiscoveredServer(
    serverUrl: 'http://localhost:8080',
    status: {'service': 'ledger', 'port': 8080},
  );

  return [err.message, rc.retryDelaysMs.length, ds.service, ds.port];
  // ['locked', 5, 'ledger', 8080]
}
```

## Tests

Bridge coverage lives in
[`test/replay/test_d4rt_tom_dist_ledger.d4rt`](../test/replay/test_d4rt_tom_dist_ledger.d4rt),
run via the replay harness (`d4rt -run-replay <file> -test`, see
[`doc/testing.md`](testing.md)). The suite exercises the four enums
(`HeartbeatErrorType`/`DLLogLevel`/`FrameState`/`OperationState`), the
`HeartbeatError` carrier, `RetryConfig` + `kDefaultRetryDelaysMs`, and the
`DiscoveredServer` getters.

> **Status (refactoring pass):** the bridge was regenerated 2026-06-15 from the
> 9 source files reachable through `tom_dist_ledger.dart` (upstream pubspec
> `version: 0.1.1`). The previous replay test was partly **stale** — its note
> claimed `FrameState`/`OperationState` are "NOT exported/bridged", but the
> current bridge **does** register both — and it was rewritten/extended against
> the current surface. The documented/tested API was verified **natively**
> (plain-Dart construction, no d4rt) — 20/20 assertions pass (including the
> `DLLogLevelExtension` upper-case `.name` override, the four enums' `.values`
> counts, `DiscoveryOptions` defaults, `DiscoveredServer` map-derived getters,
> and `RetryConfig`/`kDefaultRetryDelaysMs`).
>
> The former **generation defect (B4)** — where the generated file emitted a
> direct `import` of `call_callback.dart` (a `part of 'ledger_api.dart'`),
> which the CFE rejected — is now resolved. The regenerated bridge imports the
> *owning libraries* (`ledger_api.dart`, `ledger_base.dart`, `ledger_types.dart`,
> `cleanup_handler.dart`) and reaches `call_callback.dart` transitively, so the
> part-import clash is gone. `dart analyze lib/src/tom_dist_ledger` is clean.
