# tom_reflection bridge

The `tom_reflection` bridge exposes the capability/mirror reflection API of
`package:tom_reflection` (a code-generation–based reflection system in the
spirit of `package:reflectable`) to D4rt scripts. Bridges are generated by
`d4rtgen` into `lib/src/tom_reflection/tom_reflection_bridges.b.dart` and
registered through `TomDartscriptBridges.register` (see
[`README.md`](../README.md)).

Scripts reach this surface by importing the upstream barrel:

```dart
import 'package:tom_reflection/tom_reflection.dart';
```

## What it is

`tom_reflection` describes *how much* reflection a class needs through
**capabilities**, then exposes the reflected structure through **mirror**
interfaces — the same shape as `dart:mirrors`, but driven by generated code so
it works in environments where `dart:mirrors` is unavailable. The bridge makes
the capability marker classes, the mirror interfaces, the error types, and the
ready-made capability singletons reachable from D4rt.

> Most of this surface is *abstract* (the mirror interfaces) or *const marker*
> classes used as annotation metadata. From a script you typically reference
> the pre-built capability singletons (e.g. `instanceInvokeCapability`) and the
> small set of instantiable capability classes; the mirror interfaces are
> reachable as types but are produced by a reflector at runtime.

## Bridged classes

### Core types

| Class | Purpose |
| ----- | ------- |
| `ReflectionInterface` | The contract a reflector implements (`canReflect`, `reflect`, `reflectType`, `findLibrary`, `libraries`, `annotatedClasses`). |
| `Reflection` | Base class used as annotation metadata to mark classes for reflection; carries up to ten capabilities. |
| `StringInvocation` | String-keyed `Invocation` variant (`memberName`, `positionalArguments`, `namedArguments`, `isMethod`/`isGetter`/`isSetter`/`isAccessor`). |
| `NoSuchCapabilityError` | Error thrown when a reflective operation lacks the required capability. |
| `ReflectionNoSuchMethodError` | Error thrown when an invocation target exists but the reflector lacks the capability to invoke it. |
| `TypeValue` | Carrier for a reified `Type` value. |

### Capability classes

`ReflectCapability` is the root; `ApiReflectCapability` is the base of the
per-operation capabilities. `NamePatternCapability` matches members by a
regular-expression name pattern (`namePattern`); `MetadataQuantifiedCapability`
matches by an annotation `metadataType`.

### Mirror interfaces

The mirror hierarchy mirrors `dart:mirrors`. All are abstract; instances are
produced by a reflector at runtime.

| Class | Mirrors |
| ----- | ------- |
| `Mirror` | Root marker. |
| `DeclarationMirror` | A named declaration. |
| `ObjectMirror` | An object exposing members. |
| `InstanceMirror` | A reflected instance (`reflectee`, `invoke`, …). |
| `ClosureMirror` | A reflected closure. |
| `LibraryMirror` | A library. |
| `LibraryDependencyMirror` | An import/export edge. |
| `CombinatorMirror` | A `show`/`hide` combinator. |
| `TypeMirror` | A type. |
| `ClassMirror` | A class. |
| `FunctionTypeMirror` | A function type. |
| `TypeVariableMirror` | A type variable. |
| `TypedefMirror` | A typedef. |
| `MethodMirror` | A method/constructor/accessor. |
| `VariableMirror` | A field/variable. |
| `ParameterMirror` | A parameter. |
| `SourceLocation` | A source position. |
| `Comment` | A documentation comment. |

## Enums

| Enum | Values |
| ---- | ------ |
| `StringInvocationKind` | `method`, `getter`, `setter`, `constructor` |

## Global capability singletons

These are ready-made `const` capability instances (shorthands for the
zero-/empty-pattern capabilities). All are bridged as global variables:

`instanceInvokeCapability`, `staticInvokeCapability`,
`topLevelInvokeCapability`, `newInstanceCapability`, `metadataCapability`,
`typeCapability`, `typeRelationsCapability`, `reflectedTypeCapability`,
`libraryCapability`, `declarationsCapability`, `uriCapability`,
`libraryDependenciesCapability`, `invokingCapability`, `typingCapability`,
`delegateCapability`, `subtypeQuantifyCapability`,
`superclassQuantifyCapability`, `typeAnnotationQuantifyCapability`,
`typeAnnotationDeepQuantifyCapability`, `correspondingSetterQuantifyCapability`,
`admitSubtypeCapability`.

The name-pattern singletons (`instanceInvokeCapability`,
`staticInvokeCapability`, `topLevelInvokeCapability`, `newInstanceCapability`,
`invokingCapability`) are built with an empty pattern, so their `namePattern`
is `''` (match all).

## Global functions

The five reflection no-such-member error constructors are exposed as
top-level functions:

| Function | Builds |
| -------- | ------ |
| `reflectionNoSuchInvokableError` | A generic no-such-invokable error. |
| `reflectionNoSuchMethodError` | A no-such-method error. |
| `reflectionNoSuchGetterError` | A no-such-getter error. |
| `reflectionNoSuchSetterError` | A no-such-setter error. |
| `reflectionNoSuchConstructorError` | A no-such-constructor error. |

## Example

```dart
import 'package:tom_reflection/tom_reflection.dart';

main() {
  // Build a name-pattern capability and read its pattern back.
  var cap = InstanceInvokeCapability('greet');
  // cap.namePattern == 'greet'

  // The ready-made singleton matches all members (empty pattern).
  var all = instanceInvokeCapability.namePattern; // ''

  // Enum members.
  var kind = StringInvocationKind.getter.name; // 'getter'

  return [cap.namePattern, all, kind];
}
```
