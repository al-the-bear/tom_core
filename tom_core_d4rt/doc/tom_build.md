# tom_build bridge

The `tom_build` bridge exposes the Tom Framework build toolkit
(`package:tom_build`) to D4rt scripts — the workspace analyzer, the reflection
generator runner, the DCli-style scripting helpers (`TomText`, `TomPth`,
`TomFs`, `TomShell`, …), the `.tom`-workspace file-object-model, and the
tool/platform context. Bridges are generated by `d4rtgen` into
`lib/src/tom_build/tom_build_bridges.b.dart` and registered through
`TomDartscriptBridges.register` (see [`README.md`](../README.md)).

Scripts reach this surface by importing the upstream barrel:

```dart
import 'package:tom_build/tom_build.dart';
```

The bridge covers all 17 source files exported by `tom_build.dart` (57 classes,
2 enums, 1 global variable, 5 top-level functions).

## Example

```dart
import 'package:tom_build/tom_build.dart';

main() {
  // String transforms (static helpers).
  var id = TomText.camelCase('my build step');   // 'myBuildStep'
  var base = TomPth.basename('/a/b/c.txt');       // 'c.txt'

  // Platform + mode validation.
  var plat = PlatformInfo.detect();
  var ok = ModeValidationResult.success(['dev']);

  return [id, base, plat.toString(), ok.isValid];
}
```
