# cli

> These packages are BSD-3-Clause licensed and internal (`publish_to: none`).

CLI internals for the `d4rt` tool. Unlike its siblings under `lib/src/`, this is
**not a package bridge** — it holds the interactive-REPL wiring and the
build-stamped version info that back the thin `bin/d4rt.dart` entry point.

## Key types

| Type | What it is |
| ---- | ---------- |
| `D4rtRepl` | The REPL. Extends `D4rtReplBase` (from `tom_d4rt_dcli`) with `VSCodeIntegrationMixin`, registers every Tom bridge via `TomDartscriptBridges.register`, and adds `.d4rt`/`.dcli` replay support and VS Code integration. |
| `TomVersionInfo` | Generated by the `versioner` build step — static `version`/`buildTime`/`gitCommit`/`buildNumber` constants surfaced by the `-v` flag and `toolVersion`. |

## Run

```bash
# Launch the REPL with all Tom bridges pre-registered.
dart run bin/d4rt.dart
```

`version.versioner.dart` is regenerated at build time and must not be edited by
hand.
